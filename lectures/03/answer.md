## 宿題

- 取り組んだレベル：基礎
- やったこと：`app/agent.py` の `INSTRUCTIONS` 回答形式を統一するための指示を追加した

    回答するときは、以下の形式を守る
        1. 結論
        2. 理由・根拠
        3. 具体例
        4. 関連する講義回

- 結果：
    ```$ uv run python -m app.agent --trace "LoRAとQLoRAの違いは？"```

    [model] gemini-3.5-flash-lite
    1. **結論**
    LoRAとQLoRAの主な違いは、**ベースモデルの重みをそのまま（通常の精度で）使うか、量子化（4ビットなど）してメモリを大幅に節約するかの違い**です。

    2. **理由・根拠**
    - **LoRA**は、事前学習済みの重みを固定したまま、重みの更新分を低ランク行列で近似し、その小さな行列だけを学習して効率化を図る手法です。
    - **QLoRA**は、LoRAの仕組みをベースにしつつ、ベースモデルの重みを4ビット量子化（NF4など）に圧縮して読み込むことで、GPUのメモリ消費量をさらに劇的に削減します。その上で、量子化による精度低下を防ぐ工夫（二重量子化やPaged Optimizersなど）を加えて学習を行います。

    3. **具体例**
    - **LoRA**：13B（130億パラメータ）クラスのモデルを学習する際、重みはそのまま（FP16やBF16など）でLoRA層を追加して学習します。
    - **QLoRA**：同じ13Bクラス（あるいはそれ以上の大規模なモデル）の重みを4ビットに圧縮してメモリに載せ、より限られたGPU環境でもLoRAと同様の効率的なファインチューニングを行えるようにします。

    4. **関連する講義回**
    - 第2回

- 気づき・疑問：`INSTRUCTIONS` に回答形式を具体的に指定することで、エージェントの回答構成をある程度コントロールできることが分かった。
